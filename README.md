# MTG Deck Builder

A Commander (EDH) deck builder that runs entirely in the browser. It uses EDHREC for recommendations and Scryfall for card search, artwork and prices.

- **Open the app:** see the GitHub Pages link in the repo's About section.
- **Your decks** are stored in your own browser. Use "Save file with decks" to share them as one file.
- The whole app is a single file: `index.html`.
